# 🎬 Movie Dashboard

A modern **Movie Dashboard web application** that allows users to explore movies, manage their favorites, and discover popular actors and filmmakers.

---

##  Features

### 🔍 Home / Explore Movies
- Search movies by name
- Browse popular & trending movies
- View movie details (poster, title, release date)
- Add movies to favorites 

###  Favorites
- View all favorited movies in one place
- Remove movies from favorites
- Favorites persist using Local Storage

### 👥 People
- Browse popular actors, actresses, and directors
- View profile image and known movies
- Explore movies associated with a person

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Styling:** Tailwind CSS
- **API:** TMDB (The Movie Database API)  
- **State Management:** React Hooks & Context API  
- **Storage:** LocalStorage
